# 🏡 Уютный Дом — Поиск предметов и Ремонт

2D браузерная игра в жанре **Hidden Object & Renovation**, созданная для комфортной,
спокойной игры (крупный интерфейс, без таймера и штрафов). Один файл `index.html` —
чистый HTML5 Canvas + JavaScript, без внешних зависимостей.

## 🎮 Как играть
1. **Уровень 1 — Чердак:** найдите 10 спрятанных предметов. За каждый +100 монет.
   Есть кнопка **«🔍 Подсказка»** — вокруг предмета появится золотое кольцо.
2. **Уровень 2 — Ремонт:** выберите стиль — 🌷 *Уютный Прованс* или 📚 *Классическая Библиотека*.
   Комната преобразится с плавным переходом.
3. **Финал:** обновлённый дом с садом. Кнопка **«Играть снова»**.

## 🎨 Работает без установки
Игра **полностью самодостаточна** — все сцены (чердак, комната до/после ремонта, дом с садом)
и спрятанные предметы нарисованы прямо в коде. Ничего дополнительно загружать НЕ нужно.

## 🖼️ (Необязательно) Свои картинки
Если хотите заменить нарисованные сцены на свои иллюстрации — положите картинки
**в ту же папку**, что и `index.html`, с этими **точными** именами. Игра подхватит их сама:

| Имя файла      | Роль в игре                               |
|----------------|-------------------------------------------|
| `image_4.png`  | Уровень 1 — Чердак (поиск предметов)      |
| `image.png`    | Уровень 2 — Старая комната (до ремонта)   |
| `image_5.png`  | Уровень 2 — Вариант «Уютный Прованс»      |
| `image_3.png`  | Уровень 2 — Вариант «Классическая Библиотека» |
| `image_2.png`  | Финал — Дом с садом                       |

> Соответствие вашим фото: 1-е фото (чердак) → `image_4.png`; 2-е (тёмная комната) → `image.png`;
> 3-е (светлая гостиная) → `image_5.png`; 4-е (библиотека) → `image_3.png`; 5-е (дом с садом) → `image_2.png`.

### Как загрузить через сайт GitHub
1. Откройте репозиторий → кнопка **Add file → Upload files**.
2. Перетащите 5 картинок, переименовав их согласно таблице выше.
3. **Commit** — деплой на GitHub Pages запустится автоматически.

## ▶️ Локальный запуск
```bash
python3 serve.py
# затем откройте http://localhost:8000
```
Или любой статический сервер, например:
```bash
npx serve .
```

## 🚀 Публикация (GitHub Pages)
Workflow `.github/workflows/deploy-pages.yml` автоматически публикует игру на GitHub Pages
при пуше в ветку. Адрес после деплоя:
```
https://<владелец>.github.io/<репозиторий>/
```
Для этого репозитория: **https://arslanamirov03-arch.github.io/MyApp/**

Если деплой не стартовал: Settings → Pages → Source → **GitHub Actions**.

## 📐 Технологии
- HTML5 Canvas (рендер сцен, искры, подсветка), DOM-оверлей для крупного доступного UI.
- WebAudio API для мягких звуковых сигналов (без внешних файлов).
- Адаптивная вёрстка 16:9 (ПК, планшет, телефон).
