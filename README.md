# ДИСЦИПЛИНА · HÖREN

Android-приложение для учёта активной слуховой практики немецкого языка.

**Цель зашита намертво: 60 часов с 1 по 31 августа 2026 года.**

## Как работает норма

Норма на день считается от того, что сделано **до** этого дня:

```
норма(d) = ceil( (3600 минут − сделано до дня d) / (31 − d + 1) )
```

- На 1 августа при пустом журнале это **1:57** в день.
- Пропустил день — норма на все оставшиеся дни автоматически выросла.
- Переработал — норма следующих дней снизилась.
- Внутри дня норма не меняется: она зафиксирована на начало дня, поэтому цель
  не «убегает» по мере практики.
- При выполнении нормы каждый день итог сходится **ровно в 3600 минут** — это
  проверено юнит-тестами (`app/src/test/.../PlanTest.kt`).

## Как пользоваться

1. Открыть приложение — оно само знает дату и время.
2. **СТАРТ СЕЙЧАС** перед практикой, либо **УКАЗАТЬ ВРЕМЯ НАЧАЛА**, если забыл
   отметиться вовремя.
3. Уйти слушать.
4. Вернуться, нажать **СТОП СЕЙЧАС** либо **УКАЗАТЬ ВРЕМЯ КОНЦА**. Приложение
   само посчитает длительность и запишет её в день.
5. Повторять, пока норма дня не закрыта. Сессий за день может быть сколько угодно.

Сессия, начатая до полуночи и законченная после, считается корректно и
относится ко дню начала.

### Экраны

| Вкладка | Что делает |
|---|---|
| **СЕГОДНЯ** | Норма дня, кольцо выполнения, СТАРТ/СТОП, журнал за сегодня, цитата дня |
| **ПЛАН** | Календарь августа: цвет каждого дня по статусу. Нажатие на день открывает его редактор |
| **СВОДКА** | Общий прогресс к 60 часам, отставание/опережение, серия ударных дней, прогноз закрытия, диаграмма по дням |

Любой день можно открыть и исправить: поменять время начала или конца любой
сессии, добавить пропущенную запись задним числом, удалить лишнюю. Правка сразу
пересчитывает нормы последующих дней — общая цель в 60 часов не меняется.

## Цитаты

Цитаты Сталина взяты из опубликованных речей и докладов (Сочинения, тт. 10, 13,
14) с указанием повода и даты. По интернету ходит много апокрифов, приписанных
ему задним числом, — таких в подборке нет. Строки, написанные для самого
приложения, подписаны «ШТАБ ПЛАНА», а не отданы историческим лицам. Подборку
дополняют Ленин, Суворов, Островский и немецкие пословицы по теме практики.

## Сборка

```bash
./gradlew assembleRelease          # APK в app/build/outputs/apk/release/
./gradlew testDebugUnitTest        # юнит-тесты математики плана + рендер экранов
./gradlew testDebugUnitTest -Pscreens=true   # плюс снимки экранов в app/build/screens/
```

Требуется Android SDK (platform 35, build-tools 35.0.0) и JDK 17. Путь к SDK
задаётся в `local.properties` (`sdk.dir=...`) или переменной `ANDROID_HOME`.

Сборку в облаке делает `.github/workflows/build-apk.yml`: гоняет тесты, собирает
релизный APK и публикует его в релиз с постоянным тегом `apk-latest`.

### О ключе подписи

`keystore/discipline.jks` лежит в репозитории, пароль — `disziplin1937`. Это
осознанный размен: приложение личное и в маркеты не публикуется, а постоянный
ключ позволяет ставить обновления поверх старой версии. Если репозиторий станет
публичным и это будет нежелательно, ключ надо заменить и перенести пароль в
секреты GitHub Actions.

## Стек

Kotlin 2.0.21, Jetpack Compose (BOM 2024.10.01), Material 3, AGP 8.7.3,
compileSdk 35, minSdk 24.

Зависимостей намеренно минимум: нет Room, Retrofit, KSP и navigation-compose.
Даты и время хранятся целыми числами (день августа 1..31 и минуты от полуночи),
поэтому `java.time` и core library desugaring не нужны. Журнал лежит в
`SharedPreferences` в виде JSON.
