# Hörpraxis

Android-приложение для тренировки немецкого аудирования. Полностью офлайн — без API и интернета.

## Что умеет

- **Добавление аудио и видео** (MP3, M4A, WAV, MP4, MKV, OGG…) кнопкой «+» — приложение само достаёт аудиодорожку. После добавления вы сами выбираете: распознать речь или вставить готовый текст.
- **Офлайн-распознавание немецкой речи** через [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (модель `small` q8_0; скачивается один раз при первом использовании, дальше интернет не нужен).
- **Транскрипция с таймингом каждого слова** (DTW-выравнивание): нажатие на любое слово продолжает воспроизведение точно с него.
- **Готовый текст**: если транскрипция уже есть, её можно вставить, а потом уточнить тайминги по звуку — распознавание измерит время, а ваш текст останется как есть.
- **Подсветка текущего слова** во время воспроизведения с автопрокруткой (отключается в настройках).
- **Режим «Разбор»** с двумя вариантами: «Слово» — нажатое слово повторяется бесконечно; «Предложение» — отмечаете первое и последнее слово, и кусок любой длины повторяется по кругу.
- **Редактирование**: исправление отдельного слова или всего текста с сохранением таймингов.
- **Скорость воспроизведения** 0.5×–2× и перемотка ±5 секунд.
- **Свайп по карточке влево** открывает две цветные кнопки: переименовать и удалить.
- **Прогресс сохраняется**: позиция и скорость каждой записи запоминаются.

## Сборка

Требования: JDK 17+, Android SDK (platform 35, NDK 27.2, CMake 3.22).

```bash
./gradlew :app:assembleRelease
```

По умолчанию APK собирается без модели (~15 МБ) — приложение скачивает её при первом использовании. Чтобы зашить модель в APK (~280 МБ, полностью автономная установка), соберите с `-PbundleModel`:

```bash
./gradlew :app:assembleRelease -PbundleModel
```

## Архитектура

- `app/src/main/cpp` — JNI-обвязка + исходники whisper.cpp/ggml (CPU, arm64-v8a, FP16).
- `audio/AudioDecoder.kt` — MediaExtractor/MediaCodec → 16 кГц моно PCM с потоковым ресемплингом.
- `transcribe/TranscribeService.kt` — foreground-сервис, распознаёт очередь файлов с прогрессом в уведомлении.
- `data/Repository.kt` — библиотека, транскрипции и настройки в JSON в приватном хранилище.
- `data/TranscriptAligner.kt` — раскладка вставленного текста по времени и выравнивание его на распознанные слова.
- `ui/` — Jetpack Compose, Material 3, светлая тема.
