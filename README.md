# Lexis — слова наизусть

Приложение для набора и повторения слов — начиналось с немецкого,
но не привязано к языку. Работает без интернета:
все данные лежат в памяти устройства.

## Что умеет

- **Блоки → списки → слова.** Блок объединяет списки по теме или уровню
  («German Words B1»), в одном списке ровно до **500 слов**. Когда список
  заполнен, форма ввода закрывается и предлагается создать следующий.
- **Разбор по интервалам.** Показывается перевод — вы пишете слово
  по-немецки. Верный ответ поднимает слово на следующую ступень:
  **1 → 2 → 3 → 7 → 14 → 30 → 90 дней**, после последней слово считается освоенным.
  Если ответ не совпал, есть два пути: «Опечатка» (засчитывается как верный)
  и «Забыл» — тогда слово возвращается в самое начало лестницы,
  даже если стояло на 90 днях.
- **Учебный день начинается в 6 утра.** Слово, добавленное вечером, ждёт не
  того же часа на следующие сутки, а всплывает в 6:00 — и появляется на экране
  само, без перезапуска. Ночь до 6 утра относится к прошедшему дню.
  Приложение показывает текущее время и то, когда откроется следующая партия.
- **Знакомство десятками.** Новые слова сначала показываются по одному —
  слово, перевод и картинка, — а после каждой десятки идёт проверка на этих же
  словах. 22 слова разбираются как 10, 10 и 2. Только пройдя проверку, слово
  встаёт на лестницу повторений.
- **Картинка к слову** — тремя путями: снимок с устройства, рисунок от Gemini
  («Nano Banana») по ключу Google AI и бесплатный обходной путь: кнопка
  «Промпт» кладёт готовый запрос в буфер, картинку можно нарисовать где
  угодно, а кнопка «Вставить» принимает её обратно. Промпт требует
  изображения без единой буквы — в том числе на книгах, экранах и вывесках,
  иначе картинка подсказывала бы ответ. Картинку можно убрать или заменить.
- **Проверка без подсказок.** Поле ответа устроено так, что клавиатура не
  предлагает готовые слова в верхней строке — иначе проверка теряет смысл.
  Клавиатура не открывается сама, чтобы экран не подпрыгивал на каждом слове.
  Верный ответ сразу уводит к следующему слову; сроки при этом не показываются.
  Прямо в проверке есть «Забыл» (слово покажут и вернут в начало), правка слова
  вместе с картинкой и переключение размера карточки.
- **Повторы видно сразу.** Слово, записанное не один раз, помечено в списке —
  можно посмотреть, где ещё оно лежит. При добавлении такого же слова
  приложение спрашивает, оставить его или убрать.
- **Удаление спрашивает подтверждение**, чтобы случайное касание не стоило слова.
- **Список слов сворачивается** кнопкой «Завернуть», чтобы не мешал;
  состояние запоминается.
- **Выгрузка списка** в PDF, Word (.docx) и обычный текст. Текст в файлах
  настоящий и извлекаемый — их можно отправлять языковой модели.
- **Резервная копия** всей картотеки одним файлом.

## Как устроено

| Что | Где |
| --- | --- |
| Разметка и стили | `src/index.html`, `src/styles.css` |
| Данные, расписание и хранение | `src/js/store.js` |
| Экраны и переходы | `src/js/ui.js` |
| Картинки и обращение к Gemini | `src/js/media.js` |
| Выгрузки | `src/js/export.js`, `src/js/pdf.js`, `src/js/docx.js`, `src/js/zip.js`, `src/js/ttf.js` |
| Шрифты для PDF | `assets/fonts/` |
| Оболочка Android | `android/` |

PDF и DOCX собираются без сторонних библиотек. В PDF встраивается шрифт
(CIDFontType2, Identity-H) вместе с картой ToUnicode — поэтому немецкие
умляуты и кириллица и печатаются, и корректно копируются из готового файла.
DOCX собирается собственным ZIP-писателем и открывается как обычная
таблица Word.

## Сборка

```bash
npm install
npm run build          # dist/index.html и dist/artifact.html
npm test               # проверки в настоящем браузере
npm run check:exports  # собрать пробные PDF/DOCX/TXT
```

Проверки идут в пять прогонов: путь пользователя (`e2e.mjs`), расписание
на подменённых часах (`e2e-time.mjs`), картинки с подменённым ответом Gemini
(`e2e-images.mjs`), сохранность прогресса при очистке хранилища
(`e2e-storage.mjs`) и сборка для публикации (`check-artifact.mjs`).

Ключ Google AI в репозитории не хранится: он вводится в самом приложении,
лежит на устройстве и не попадает ни в резервную копию, ни в сборку.
Картинки хранятся в базе данных устройства — в обычное хранилище браузера
сотни снимков не поместились бы.

Прогресс пишется сразу в две ячейки хранилища и дублируется в базу данных
устройства, а перед закрытием страницы дописывается принудительно — потеря
любой одной копии не стоит пользователю ни одного слова.

`scripts/build.mjs` складывает стили, скрипты и шрифты в один самодостаточный
HTML-файл. Он же копируется в `android/app/src/main/assets/`, поэтому
приложение и сайт всегда одинаковы.

## Установка на телефон

Готовое приложение лежит в `release/lexis-1.0.apk` — файл скачивается
по прямой ссылке одним переходом:

https://raw.githubusercontent.com/arslanamirov03-arch/MyApp/refs/heads/claude/german-vocabulary-app-epeejr/release/lexis-1.0.apk

Собрать заново:

```bash
node scripts/build.mjs
cd android && gradle assembleDebug
```

Страница внутри приложения отдаётся через `WebViewAssetLoader` с постоянного
адреса `https://appassets.androidplatform.net/`. Это важно вдвойне: у страницы
появляется постоянный источник, поэтому не пропадает сохранённый прогресс,
и запросы к Google уходят нормально — со страницы, открытой прямо из файла,
браузер их не выпускает.
