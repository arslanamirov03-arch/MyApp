# Снятие стресса

Android-приложение для снятия стресса. Три режима — костёр, гроза и бомба, все
считаются на GPU в реальном времени.

## Как пользоваться

1. **Меню** → кнопка «НАЧАТЬ».
2. **Выбор режима** → «ОГОНЬ», «МОЛНИЯ» или «БОМБА» («ВОДА» помечена «СКОРО»).

### Огонь

- короткое касание — вспышка как от спички;
- удержание — костёр растёт (~9 секунд до максимума), под пламенем разгорается
  слой углей, экран начинает трястись, звук становится ниже и громче;
- палец можно **водить** — пламя тянется за ним, движение толкает газ;
- когда огонь занимает весь экран — **взрыв**: вспышка, ударная волна,
  сильная тряска и вибрация, затем снова чёрный экран.

### Молния

- короткое касание — **один** разряд с неба, ярко-синий, со своим раскатом;
- каждый разряд случайный: шесть типов канала (прямой, ветвистый, вилка,
  ступенчатый, лента, блуждающий), своё число повторных ударов и своё мерцание;
- удержание — разряды учащаются и расходятся по всему экрану, облака
  подсвечиваются изнутри, экран светлеет и трясётся; на пике весь экран залит
  очень частыми молниями;
- когда отпускаешь — разряды прекращаются быстро, а гул грозы уходит
  постепенно, ещё несколько секунд, с редкими далёкими вспышками.

### Бомба

- короткое касание — **взрыв сразу**; заряд каждый раз случайный из пяти:
  фугас (оранжевый), термобарический (густо-красный, медленный),
  фосфорный (бело-голубая вспышка), тяжёлый (глухой) и плазменный (синий);
- удержание — начинается **обратный отсчёт**: экран дрожит, по углам пульсирует
  красный туман, включается сирена, а писк ускоряется по мере приближения;
- **18 секунд** — самое долгое удержание в приложении;
- в конце — ядерный взрыв: слепящая вспышка, ударная волна на весь экран,
  сильнейшая тряска и вибрация, затем огненный шар всплывает и **сам собой
  сворачивается в грибовидное облако**, которое ещё долго висит и оседает.
  Гул держится почти полминуты.

## Как сделан огонь

Это не видео и не спрайты — каждый кадр решается 2D-уравнение Навье-Стокса
на сетке (около 200x430 ячеек) и поверх него — модель горения:

| Проход | Что делает |
| --- | --- |
| `curl.frag` | завихренность поля скоростей |
| `velocity.frag` | полулагранжева адвекция + vorticity confinement, тепловая подъёмная сила, турбулентность из curl-шума, импульс от пальца, ударная волна взрыва |
| `divergence.frag` → `pressure.frag` (x26) → `project.frag` | проекция Гельмгольца: поле скоростей становится бездивергентным |
| `advect.frag` → `fields.frag` | перенос температуры / топлива / сажи схемой MacCormack (второй порядок: перенос вперёд, назад и коррекция с ограничителем), горение первого порядка, радиационное охлаждение |
| `particles_update.frag` | искры-угольки летят по полю скоростей (GPU, 4096 штук) |
| `render_fire.frag` | излучение абсолютно чёрного тела по температуре, доменное искажение curl-шумом для деталей мельче сетки, дым, слой углей под пламенем |
| `bloom_*.frag` | свечение (5 уровней) |
| `composite.frag` | тряска камеры, ударная волна, хроматическая аберрация, ACES-тонмаппинг, зерно |

## Как сделана бомба

Взрывы считает **тот же самый** решатель Навье-Стокса, что и костёр — просто
вместо горящей подушки топлива в поле вбрасывается импульс давления и вспышка
тепла. Разные заряды — это разные числа: скорость расширения, количество сажи и
цветовая градуировка (`uTint`, `uKelvinBase`, `uKelvinSpan` в `render_fire.frag`).

Грибовидное облако **не нарисовано и не анимировано вручную**. Компактный очень
горячий сгусток, выпущенный низко в среде с малым затуханием и сильным
vorticity confinement, сам сворачивается в тороидальный вихрь и вытягивает за
собой ножку — именно так ведёт себя всплывающий термик в реальности. Задача кода
— только удерживать нужные параметры достаточно долго.

## Как сделана молния

Молния — не картинка, а построенный на лету канал. Ломаная от неба до точки
удара многократно делится пополам со случайным смещением середины (midpoint
displacement), от неё отходят ветви, и всё это разворачивается в полосы с общими
стыками, чтобы аддитивное смешивание не давало «бусин» на канале.

| Часть | Что делает |
| --- | --- |
| `Bolt.java` | геометрия канала и ветвей, шесть стилей, повторные удары (канал перестраивается и вспыхивает снова, как у настоящей молнии) |
| `bolt.vert` / `bolt.frag` | тонкое белое ядро внутри мягкого синего ореола |
| `storm_sky.frag` | слой облаков, подсвеченный изнутри самими разрядами (до 6 источников света) |
| `StormState.java` | нарастание грозы, частота и разброс ударов, тряска, медленное затухание после отпускания |

## Звук

Всё синтезируется процедурно (`tools/gen_audio.py`), готовых сэмплов нет.

**Гром** считается по физике: канал молнии разбивается на 90 участков на разном
расстоянии, звук от каждого приходит в своё время и тем глуше, чем дальше
участок (воздух съедает верха). Поэтому у близкого удара есть щелчок, а у
далёкого — только рокот. Эхо добавляется отдельно: у **одиночного** разряда один
чёткий отражённый хлопок и тишина, а **во время грозы** — 11 наложенных
отражений, которые и дают непрерывный раскат.

Отдельно есть тонкомпенсация (`shape_for_speaker`): физически честный гром почти
весь лежит ниже 120 Гц, а телефонный динамик такие частоты просто не
воспроизводит, поэтому спектр подтягивается в ту полосу, где щелчок слышно.

Остальное: слой пламени с потрескиваниями, суб-бас, спичка, взрыв, четыре
заряда бомбы, сирена с ускоряющимся писком, ядерный взрыв и долгий гул после
него.

## Сборка

```bash
./gradlew assembleDebug          # APK для установки
./gradlew assembleRelease        # подписывается, если есть keystore/release.jks
```

Требуется Android SDK 34 и JDK 17.

## Инструменты разработки

| Скрипт | Назначение |
| --- | --- |
| `tools/validate_shaders.py` | прогоняет все шейдеры через `glslangValidator` в обоих режимах точности |
| `tools/preview.py` | запускает **тот же самый** конвейер шейдеров огня на десктопном OpenGL без телефона и сохраняет кадры — так подбирались все константы |
| `tools/storm_preview.py` | то же для грозы: повторяет генератор молний из `Bolt.java` и рисует теми же шейдерами |
| `tools/bomb_preview.py` | то же для бомбы: повторяет `BombState.java` и гоняет тот же решатель — так проверялось, что грибовидное облако действительно образуется |
| `tools/gen_noise.py` | генерирует бесшовную fBm-текстуру шума |
| `tools/gen_audio.py` | генерирует WAV-ассеты |
| `tools/gen_icon.py` | генерирует иконки приложения |

Например, посмотреть огонь на 65% интенсивности:

```bash
python3 tools/preview.py --fixed 0.65 --seconds 4.5 --shots 4.2 --out preview
```

Посмотреть грозу от одиночного разряда до пика:

```bash
python3 tools/storm_preview.py --w 540 --h 1170 --shots 0.33,4.6,9.2 --out preview
```

Посмотреть ядерный взрыв (с укороченным отсчётом, иначе рендер слишком долгий):

```bash
python3 tools/bomb_preview.py --nuke --arm 1.0 --seconds 18 \
    --shots 1.35,2.5,7.5,16.5 --out preview
```

## Совместимость

- Android 7.0+ (minSdk 24), требуется OpenGL ES 3.0.
- На GPU без рендеринга в float-текстуры автоматически включается запасной
  8-битный режим (`#define LOWPREC 1`), искры при этом отключаются.
- Число итераций решателя давления подстраивается под частоту кадров.
