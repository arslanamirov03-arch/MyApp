# Simple APK (demo)

Минимальное Android-приложение (один экран, TextView) для демонстрации
автоматической сборки APK через GitHub Actions.

## Как собирается APK

При каждом push, затрагивающем папку `simple-apk/`, запускается workflow
[`build-simple-apk.yml`](../.github/workflows/build-simple-apk.yml), который:

1. Собирает debug APK через Gradle на серверах GitHub (Ubuntu + Android SDK).
2. Прикладывает APK как **artifact** к запуску Action.
3. Публикует APK как файл к **GitHub Release** — самый простой способ скачать
   готовый `.apk` на телефон.

## Как установить APK на Android

1. Открой раздел **Releases** этого репозитория на GitHub.
2. Скачай на телефоне файл `app-debug.apk` из последнего релиза.
3. При первой установке Android спросит разрешение "Установить из
   неизвестного источника" — разреши для браузера/файлового менеджера,
   через который открываешь файл.
4. Нажми **Установить**.

Либо, если релиза нет — скачай архив из **Actions → выбранный run → Artifacts**
(он будет в zip, внутри — apk).
