# BRO FORCE — мобильный run-and-gun

Броforce-подобный экшен для Android. Одна пуля убивает, три жизни, длинный путь
вправо через 5 карт по 5 уровней, в конце каждой карты — свой босс.

Всё содержимое игры генерируется кодом: спрайты, тайлы, фоны, уровни, звуки и
музыка. В APK нет ни одного файла ассетов — поэтому он весит ~110 КБ.

## Сборка

```bash
export ANDROID_HOME=/path/to/android-sdk     # нужен platform 34 + build-tools 34
echo "sdk.dir=$ANDROID_HOME" > local.properties
gradle assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

## Управление

| Действие          | Как                                          |
|-------------------|----------------------------------------------|
| Идти              | джойстик влево / вправо                      |
| Прыжок            | джойстик вверх (держать — прыжок выше)       |
| Присесть          | джойстик вниз                                |
| Спрыгнуть с платформы | присесть + вверх                         |
| Огонь             | большая круглая кнопка (удержание — очередь) |
| Граната           | круглая кнопка слева от огня                 |
| Нож               | маленькая кнопка (добивание вплотную)        |
| Смена оружия      | стрелки ◄ ► у бокса с оружием                |
| Пауза / настройки | шестерёнка в правом верхнем углу             |

Прицеливание автоматическое: выстрел доводится по конусу вперёд, поэтому
летающих врагов и слабые точки боссов можно достать без второго стика.

## Структура кода

| Файл           | За что отвечает                                              |
|----------------|--------------------------------------------------------------|
| `GameView`     | игровой цикл, низкое разрешение + целочисленный апскейл       |
| `Art`          | спрайты как пиксельные строки над общей палитрой              |
| `Font`         | шрифт 5×7, латиница + кириллица                               |
| `Theme`        | тайлы, параллакс и погода для каждой из 5 карт                |
| `LevelGen`     | генерация 25 уровней с гарантией проходимости                 |
| `Level`        | тайловый мир, коллизии, разрушаемость                         |
| `Player`       | движение, оружие, смерть и респавн                            |
| `Enemy`        | 7 силуэтов × перекраска = 20 врагов                           |
| `Boss`         | 5 боссов, у каждого своё окно уязвимости                      |
| `Fx`           | частицы, взрывы, тряска, hit-stop                             |
| `Sfx` / `Music`| синтез звуков и чиптюн-музыки в рантайме                      |

### Гарантия проходимости

`LevelGen` строит линию земли с шагом не более 2 тайлов и ямами в 2–3 тайла с
ровной площадкой приземления, затем `clipCorridor` расчищает 5 тайлов над этой
линией. Всё, что могло бы перегородить дорогу (стены зданий, колонны), либо
переводится в фон, либо не ставится над ямой.

## Тестовый стенд

`harness/` собирает игровые классы против мини-реализации `android.graphics`
поверх Java2D — уровни можно прогонять и снимать скриншоты без устройства.

```bash
cd harness
javac -d out $(find shim -name '*.java') \
      $(ls ../app/src/main/java/com/bromobile/game/*.java | grep -vE "GameView|MainActivity") \
      src/Harness.java
java -cp out Harness reach     # доказать, что выход достижим на всех 25 уровнях
java -cp out Harness boss      # проверить, что каждый босс убиваем
java -cp out Harness play      # прогон ботом + скриншоты
java -cp out Harness screens   # отрисовать экраны меню
```

`reach` — не бот, а поиск в ширину по сетке тайлов с консервативной моделью
движения (шаг вверх ≤ 2 тайла, падение любое, прыжок ≤ 4 колонок). Именно он
поймал непроходимые стены построек, шипы вплотную к яме, здания над пропастью и
пол арены босса, встававший стеной в 4 тайла.
