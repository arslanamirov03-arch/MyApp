# Wortliste B2

Андроид-приложение со списком из **4383 немецких слов уровня B2** — тех самых,
что были в PDF `Wortliste_B2_alle_Woerter.pdf`.

## Что умеет

| Что | Как работает |
|---|---|
| Список слов | Все 4383 слова с номерами, листаются вниз одним потоком |
| Галочка «выучил» | Тап по строке — слово отмечается, счётчик сверху обновляется |
| Статистика | Сверху: сколько выучено, сколько осталось, процент и полоса прогресса |
| Поиск | Кнопка 🔍 — вводишь номер (`1243`) или слово (`gehen`) и попадаешь прямо туда |
| Копирование диапазона | Кнопка ⧉ — выбираешь «от» и «до», жмёшь «Копировать». В буфер ложится чистый список: `machen, gehen, trinken` — без номеров. Лимита нет, можно хоть все 4383 |
| Возврат на место | Открыл приложение через день — оно само прокручивается к последнему отмеченному слову |
| Сохранение | Прогресс пишется при каждой галочке сразу в три места: SharedPreferences, `state.json` и `state.bak.json`. При запуске берётся самая свежая копия |
| Экспорт/импорт | Кнопка ⋮ — «Экспорт копии» отправляет текст прогресса куда угодно (Telegram, почта, Drive), «Импорт» восстанавливает его обратно |

## Как это устроено

Одна `Activity` с `WebView`, внутри которого лежит `assets/index.html` — весь
интерфейс и логика. Никаких AndroidX и вообще никаких внешних зависимостей,
поэтому apk весит 58 КБ и собирается офлайн.

Список из 4383 строк рисуется виртуально: в DOM живёт только ~18 видимых
строк, остальные — арифметика по `scrollTop`. Поэтому прокрутка не тормозит.

```
app/
  AndroidManifest.xml
  assets/index.html    — интерфейс и вся логика
  assets/words.js      — массив из 4383 слов
  src/…/MainActivity.java  — WebView + мост в JS (сохранение, буфер, «Поделиться»)
  res/                 — иконка, строки, тема
words.json             — те же слова отдельным файлом
build.sh               — сборка apk
```

## Сборка

Нужен Android SDK (build-tools 34, platform android-34) и JDK.

```bash
ANDROID_SDK_ROOT=/путь/к/sdk ./build.sh
# готовый файл: build/WortlisteB2.apk
```

Gradle не используется — `build.sh` вызывает `aapt2`, `javac`, `d8`,
`zipalign` и `apksigner` напрямую.

### Две ловушки, на которые уже наступили

- `d8` из build-tools 34 падает с `NullPointerException`, если класс
  реализует **параметризованный** интерфейс (`ValueCallback<String>`) и собран
  на JDK 21. Поэтому `BackCallback` реализует сырой `ValueCallback`.
- Ключ подписи (`release.keystore`) в репозиторий не кладётся. Если пересобрать
  apk новым ключом, поверх старой установки он не встанет. Тогда: «Экспорт
  копии» → удалить приложение → поставить новое → «Импорт».

## Установка на телефон

Скачать `WortlisteB2.apk`, открыть на телефоне, разрешить установку из
неизвестных источников. Подпись самодельная — Android один раз спросит
подтверждение.
