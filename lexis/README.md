# Lexis — быстрые анимации

Оформление приложения Lexis (`ru.wortkabinett.app`) целиком лежит в одном файле
`assets/index.html` внутри APK: экран — это WebView, а движение задаётся стилями.
Здесь лежит обновлённая версия этого файла и скрипт, которым его кладут обратно
в APK.

Меняли только движение. Разметка, цвета, шрифты, отступы, тексты и логика
остались прежними: снимок экрана до и после совпадает попиксельно.

## Что изменилось

| Место | Было | Стало |
| --- | --- | --- |
| `--quick` — все переходы касания (нажатия, поля, кнопки, шкалы) | `.11s` | `.06s` |
| `--quick-out` — появление экранов, окон, карточек, исчезновение строк | `.15s` | `.09s` |
| `--ease` — кривая движения | `cubic-bezier(.22, 1, .36, 1)` | `cubic-bezier(.3, .95, .4, 1)` |
| `GONE` — пауза перед удалением исчезнувшего элемента | `150` мс | `90` мс |
| Курсор в разборе | `animation: caret 1.1s infinite` | статичная полоска |
| Прокрутка к полю ввода по кнопке «+» | `behavior: 'smooth'` | `behavior: 'auto'` |

Два первых значения — единственный источник времени для всего оформления:
каждый `transition` и каждая `animation` в файле ссылаются на них, поэтому
правка в `:root` разгоняет интерфейс целиком.

Про курсор отдельно: `infinite` — это анимация без конца. Пока открыт разбор,
она будит отрисовку каждую секунду и не даёт экрану простаивать, и на батарее
это самая дорогая строка во всём оформлении. Полоска теперь просто стоит.

Блок `@media (prefers-reduced-motion: reduce)` не трогали — у кого в системе
выключено движение, у того по-прежнему `.01ms`.

## Как собрать APK

```sh
python3 tools/repack_apk.py <исходный.apk> assets/index.html out-unaligned.apk
zipalign -p -f 4 out-unaligned.apk out-aligned.apk
apksigner sign --ks <ключ.jks> --ks-key-alias <алиас> --out lexis-fast.apk out-aligned.apk
apksigner verify --verbose lexis-fast.apk
```

`repack_apk.py` переписывает архив запись за записью: порядок файлов и способ
сжатия каждого сохраняются, меняется только содержимое `assets/index.html`.
Блок подписи при этом отбрасывается, поэтому `zipalign` и `apksigner` обязательны.

Подписывать нужно тем же ключом, что и предыдущую сборку, — иначе Android
считает APK другим приложением и требует сначала удалить старое.
