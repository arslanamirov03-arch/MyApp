Lexis · прототип

Приложение для изучения немецких слов

Структура по вашему описанию: Блок → Список → до 500 слов. Настройки — вверху справа, «плюс» — внизу слева (на главном добавляет блок, внутри блока — список). Учить слова можно только из блока. Ввод перевода с клавиатуры, необязательная картинка на карточке, интервалы 1 → 3 → 7 → 14 → 30 дней, очередь открывается ровно в 6:00.

Тёплые карточки, один акцент (мандарин) и цветные иконки. Собран весь флоу: главный, создание блока, блок, список со вводом слов, вставка списком, тренировка, итоги, настройки, экспорт. Всё нажимается.
