# DLS Детокс — 30 дней без Dream League Soccer 2026

Нативное Android-приложение (Kotlin), которое помогает продержаться **30 дней
подряд**, ни разу не устанавливая игру **DLS 2026 (Dream League Soccer)**.
Старт челленджа — **11 июля 2026**.

## Что умеет

- **Сетка из 30 дней** (11 июля → 9 августа). Каждый день, когда ты не играл,
  ставишь галочку — прогресс сохраняется на устройстве.
- **Отметка задним числом.** Забыл отметить вчера? Просто нажми на прошедший
  день и поставь галочку. Будущие дни отмечать нельзя.
- **Прогресс сохраняется** между запусками (SharedPreferences) — данные не
  теряются.
- **Дизайн эволюционирует вместе со стриком.** Чем длиннее серия дней подряд,
  тем богаче и необычнее становится оформление: меняется палитра, появляются
  парящие светящиеся сферы, звёзды, тёплые искры, а на 30-й день — фейерверк.
  Всего 11 визуальных уровней: от «Начало» до «ПОБЕДА».
- Круговой индикатор прогресса, счётчик текущей серии и мотивационные фразы для
  каждого уровня.

## Установка APK

1. Скачай `DLS-Detox.apk` (лежит в корне репозитория).
2. Перекинь на телефон и открой файл.
3. Разреши установку из неизвестных источников, если Android попросит.
4. Готово — иконка «DLS Детокс» появится в меню.

APK подписан отладочным ключом, поэтому устанавливается напрямую без Play Store.
`minSdk 26` (Android 8.0+), `targetSdk 35`.

## Пересборка из исходников

Собирается локально, без GitHub Actions.

```bash
# нужен Android SDK (build-tools;35.0.0, platforms;android-35) и JDK 17+
echo "sdk.dir=/путь/к/android-sdk" > local.properties
gradle :app:assembleRelease        # или ./gradlew, если сгенерировать wrapper
# результат: app/build/outputs/apk/release/app-release.apk
```
