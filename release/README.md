# Готовое приложение

`wortschatz-1.0.apk` — собранное приложение для Android 7.0 и новее.

Прямая ссылка на скачивание:

https://raw.githubusercontent.com/arslanamirov03-arch/MyApp/refs/heads/claude/german-vocabulary-app-epeejr/release/wortschatz-1.0.apk

При установке Android предупредит, что приложение не из магазина, — это обычное
дело, нужно разрешить установку из этого источника.

Файл собран из `android/` командой `gradle assembleDebug`; страница приложения
внутри — та же, что и в `dist/index.html`.
